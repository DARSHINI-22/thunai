# THUNAI — Your Scholarship Companion 🎓

### Discover Scholarships. Understand Eligibility. Take the Next Step.

**THUNAI** is a student-focused scholarship discovery and application assistance platform designed to help college students in Tamil Nadu discover relevant scholarship opportunities, understand eligibility requirements, organize necessary documents, and track their application progress.

Many students miss scholarship opportunities because information is scattered across different government portals, eligibility criteria are difficult to understand, and application requirements are not always clear.

THUNAI aims to make this process simpler, more accessible, and more organized through a single platform.

## 📖 About the Project

THUNAI is developed as part of the **ACE Builders Hackathon 2026**, under:

- **Team Name:** TESSERACT
- **Problem Statement:** 5 — Citizens and Public Services
- **Project:** Claim What's Yours
- **Domain:** Education Technology / Public Services

The platform focuses on helping students identify scholarship opportunities that may be relevant to their educational background and personal circumstances.

Instead of manually searching through multiple scholarship announcements and trying to interpret complicated eligibility rules, students can create a profile and use THUNAI to explore scholarship opportunities.

THUNAI brings scholarship discovery, eligibility assessment, document organization, application guidance, and progress tracking together in one place.

---

## 🚨 Problem Statement

India offers numerous central and state government scholarship schemes to support students from different educational, economic, and social backgrounds.

However, many eligible students fail to access these benefits because:

1. **Scattered Information:** Scholarship information is distributed across different government websites and portals.
2. **Complex Eligibility Criteria:** Students often struggle to understand complicated eligibility requirements.
3. **Unclear Documentation:** Students may not know which certificates and documents they need.
4. **Missed Opportunities:** Students may miss application opportunities because they are unaware of available schemes.
5. **Lack of Application Tracking:** Students may find it difficult to organize and monitor their scholarship applications.
6. **Information Gaps:** Students may not know whether they meet the requirements or need additional information.

These challenges create a gap between available government benefits and the students who need them.

## ✨ Key Features

### 1. Student Profile Management

Students can create and maintain a profile containing information relevant to scholarship eligibility.

Profile information includes:

- Educational level
- Category
- Tamil Nadu domicile status
- Institution details
- Institution-listing status
- Annual family income
- Class XII percentile rank
- Class XII marks
- Regular course status
- Other scholarship details
- Academic and course-related information

The profile is used by the eligibility assessment system to evaluate scholarship conditions.

Students can update their information when necessary.

### 2. Scholarship Discovery

THUNAI provides a centralized interface for exploring the scholarship records available in the application.

Students can view scholarship opportunities without manually navigating through multiple pages.

### 3. Eligibility Assessment Engine

The eligibility engine compares student profile information against the available scholarship eligibility conditions.

Each scholarship is evaluated using the information available in the student's profile.

The platform distinguishes between:

- **Likely Eligible:** Available information satisfies the evaluated conditions.
- **Not Eligible:** Available information conflicts with at least one evaluated condition.
- **More Information Required:** Important information is missing, unknown, or insufficient to make an assessment.

THUNAI does not treat missing information as automatic eligibility.

The assessment is intended as preliminary guidance, not an official scholarship approval.

### 4. Scholarship Details

Students can open individual scholarship detail pages to understand the available information about a scheme.

The details interface organizes information into sections, making scholarship information easier to navigate.

### 5. Document Checklist

Students can organize the documents associated with scholarship applications.

The checklist helps students keep track of documentation requirements and identify items that may still need attention.

Document requirements should always be confirmed against the relevant official scholarship notification.

### 6. Application Guidance

THUNAI provides an organized application guidance interface to help students understand the application process.

It is designed to make the next steps easier to follow.

### 7. Saved Scholarships

Students can save scholarships they are interested in.

This allows them to revisit relevant opportunities without searching for them again.

Students can also remove scholarships from their saved list.

### 8. Application Tracker

Students can organize and monitor their scholarship application progress.

The tracker helps students maintain an overview of their application activities and update their application status.

### 9. Scholarship Comparison

Students can compare selected scholarship opportunities.

This feature helps them examine available scholarship information together and understand differences between schemes.

### 10. Personalized Dashboard

The dashboard brings relevant student information and scholarship activity into one place.

It provides an overview of the student's scholarship journey, including relevant saved and tracked information.

## 🔄 How THUNAI Works

The basic student journey follows these steps:

**Step 1 — Visit THUNAI**

Students open the application and access the home page.

**Step 2 — Create a Student Profile**

Students enter relevant educational, academic, and personal information.

**Step 3 — Explore Scholarships**

The platform loads the available scholarship records.

**Step 4 — Check Eligibility**

The eligibility engine evaluates the student's profile against the available scheme conditions.

**Step 5 — Understand the Results**

Students can explore likely matches, unsuccessful matches, and scholarships requiring additional information.

**Step 6 — View Scholarship Details**

Students open individual scholarship pages to understand the available scheme information.

**Step 7 — Organize Documents**

Students use the document checklist to manage their preparation.

**Step 8 — Save and Track**

Students save scholarships and maintain their application progress.

**Step 9 — Monitor Progress**

The dashboard provides a consolidated overview of their scholarship activities.

## 🧠 Eligibility Assessment

The eligibility engine evaluates profile information against the conditions defined for each scholarship record.

### Eligibility categories

| Status | Meaning |
|---|---|
| Likely Eligible | Available profile information satisfies the evaluated conditions. |
| Not Eligible | Available information conflicts with an evaluated condition. |
| More Information Required | Required information is missing or unknown. |

### Unknown-value handling

A major part of the eligibility improvement is the handling of unknown answers.

For example, if a student selects "Not sure" for Tamil Nadu domicile or a course-listing question, the system should not automatically classify the student as ineligible.

Instead, the assessment should indicate that more information is required.

### Profile fields used by the eligibility engine

The profile includes information such as:

- Category
- Tamil Nadu domicile
- Institution
- Institution-listing status
- Annual family income
- Class XII percentile rank
- Class XII marks
- Regular course status
- Other scholarship received
- Whether the student dropped out after Class XII
- Full-time course status
- Prescribed course status
- Course-listing status

Class XII marks and Class XII percentile rank are maintained as separate values.

**Disclaimer:** Eligibility results are preliminary assessments based on the information and rules available in the application. They do not guarantee scholarship approval.

## 🏗️ Project Architecture

THUNAI follows a modular frontend architecture.

### Main application layers

**1. User Interface Layer**

Contains the HTML pages and CSS responsible for presenting the application.

**2. Profile Management Layer**

Handles student profile creation, validation, updating, saving, and retrieval.

**3. Scholarship Data Layer**

Contains the scholarship records used by the application.

**4. Eligibility Assessment Layer**

Evaluates profile information against scholarship conditions and generates eligibility outcomes.

**5. Feature Modules**

Handle individual functionality, including:

- Scholarship details
- Document checklist
- Application guidance
- Saved scholarships
- Application tracking
- Scholarship comparison
- Student dashboard

**6. Persistence Layer**

Uses browser local storage for supported application data.

## 🚀 Getting Started

Follow these steps to run THUNAI locally.

### Prerequisites

Make sure you have:

- Git
- A modern web browser
- Python 3 or Node.js for running a local development server

### 1. Clone the repository

```bash
git clone https://github.com/DARSHINI-22/thunai.git
```

### 2. Navigate to the project folder

```bash
cd thunai
```

### 3. Open the project

Open the repository folder in your preferred IDE.

### 4. Start a local server

Using Python:

```bash
python -m http.server 8080
```

Alternatively, if Node.js and npm are available:

```bash
npx serve .
```

### 5. Open THUNAI in your browser

For the Python server, visit:

```text
http://localhost:8080
```

The application home page is `index.html`.

To stop the Python server, press:

```text
Ctrl + C
```

## 🔐 Data Storage and Privacy

THUNAI uses browser local storage for supported profile and application data.

This allows information to persist across page refreshes in the same browser.

Important considerations:

- Data is stored locally in the user's browser.
- Clearing browser storage may remove locally saved application information.
- Data stored in one browser is not automatically synchronized with another browser or device.
- The current application does not provide a centralized student account or cloud synchronization system.
- Students should avoid using shared devices for sensitive personal information.
